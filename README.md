# Atlas-config

Configuration files for the Atlas QC pipeline (Nextflow). One directory per environment: atlas-dev/, atlas-test/, atlas-main/. Per-machine secrets live in crg_secrets.config (not published; see crg_secrets.config.example).

> **Notice (2026-10):** Development of Atlas-config has moved to an internal CRG repository (CRG staff only - not accessible from outside).
> This GitHub repository is **frozen** and kept as a public archive: to download/install a version, see the [Releases](https://github.com/proteomicsunitcrg/atlas-config/releases) (clean snapshot per release).
